  # <h1>Tamagotchi Game</h1>

In order to run this game you must meet the minimal requierements:

1. Have python 3.14 or higher
2. Have installed PyGame

if you didn't install python and pygame, here are the steps:

Steps: (Python)
1. Open your browser.
2. go on this website.
[Python Website](https://www.python.org/)
3. Download Python's latest version of your operating system.


Steps: (Pygame)
1. Open Terminal.
2. Run this command.

        pip install pygame
3. Done! 


<h3>Now that you've installed the system to run it follow these next crucial steps</3>


1. Download the Art file and the Music file in github
2. Open Visual Studio Code or Pycharm
3. create a new page called
      
        main.py
4. import The Art and Music folder into Visual Studio Code or Pycharm
5. Go back on github and look for the [main.py] code source.
6. Copy the entire page and paste it on Visual Studio code or Pycharm
7. Run the project and there you go!
